# Data Design Factory

Data Design Factory is a React application for visually designing data schemas and flows using a node-based canvas.

## Tech Stack

- React
- Vite
- XYFlow
- IndexedDB (via idb)
- ESLint

## Getting Started

### Prerequisites

- Node.js 20+
- pnpm

### Install

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

### Build

```bash
pnpm build
```

### Preview Build

```bash
pnpm preview
```

### Lint

```bash
pnpm lint
```

### Auto-fix Lint Issues

```bash
pnpm lint:fix
```
